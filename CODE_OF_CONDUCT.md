# Code of Conduct

This project follows the Contributor Covenant Code of Conduct v2.1
(https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and professional; harassment, trolling, publishing
others' private information, and other harmful behavior are unacceptable.
Reports go to the maintainers via GitHub contact or private advisory and will
be handled with discretion.
